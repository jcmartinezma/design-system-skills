# Voice and tone

Voice is stable. Tone changes with the moment. Replace the notes below with the product's real voice. Do not leave this file as a generic placeholder in a published system.

## Voice

{system-name} sounds:

- Clear: short sentences, everyday words.
- Specific: name the object ("Delete project", not "Delete").
- Calm: no blame when something fails.

## Tone by situation

| Situation | Tone | Example to replace |
|---|---|---|
| Success | Brief and confirming | "Project saved" |
| Empty | Helpful, one next step | "No projects yet" |
| Error | Direct, with a way forward | "Couldn't save. Check the connection and try again." |
| Destructive | Plain about the consequence | "Delete project? This cannot be undone." |

## Do not

- Joke in an error or a destructive confirmation.
- Use internal jargon in a label a customer reads.
- Change voice between platforms without a written reason.
